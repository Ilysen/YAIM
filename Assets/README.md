# A note on the structure of this folder

This folder holds the assets required to build the Unity asset bundle that's packaged with the mod as an embedded resource, and is essentially self-contained. Please note the following things:
* Opening YAIMSandbox.unity (the scene used to build the bundles) will make changes to YAIM.sln that will need to be reverted before you can compile the mod again, in addition to creating some superfluous project files in the root directory. I don't know how to stop this from happening, so disclaiming is all I got. The woes of being self-taught.
